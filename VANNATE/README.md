# Vannate — AI-Native Humanitarian Operating System

Vannate is an end-to-end, full-stack, production-ready prototype built to transform the humanitarian sector with AI, real-time tracking, and verified trust networks.

## Core Features
1. **Donor Dashboard:** Real-time QR identity, live donation tracking with geo-stamped route verification.
2. **Crisis Center:** Live emergency heatmaps, AI shortage forecasting, and resource prioritization.
3. **Smart Blood Bank:** AI geo-matching for rare blood groups, hospital alerts, and donor verification.
4. **NGO Operations:** AI-powered report generation, CSR proposal drafting, and compliance tracking.
5. **Volunteer Network:** Skill-based dispatching matching volunteer skills to emergency tasks.
6. **AI Copilot (Vanna):** Multilingual, voice-enabled, RAG-powered humanitarian assistant.
7. **Analytics Hub:** Live UN SDG mapping, impact measurement, and NGO VTS (Vannate Trust Score) leaderboards.

## Tech Stack
* **Framework:** Next.js 16 (App Router)
* **Styling:** Custom Vanilla CSS with Deep Glassmorphism & Micro-animations
* **AI:** Custom RAG implementation, Voice Synthesis/Recognition (Web Speech API)
* **Design System:** Ink, Teal, Gold, Purple (Premium High-Contrast Theme)

## Running Locally
1. `npm install`
2. `npm run dev`
3. Access at `http://localhost:3001` (or whichever port Next.js binds to).
